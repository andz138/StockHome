# StockHome

A secure financial analytics platform for tracking stock portfolios, analyzing financial statements, and engaging with user-driven commentary.

---

## Features

- **Authentication & Authorization**
  - JWT-based auth using ASP.NET Identity Core
  - Role-based access control for secure data usage

- **Robust Backend Architecture**
  - ASP.NET Core Web API
  - RESTful endpoints using DTOs, async EF Core operations, and MVC structure
  - SQL Server integration with EF Core Migrations

- **Portfolio Management**
  - Real-time portfolio CRUD operations
  - Dynamic schema support for flexible portfolio tracking

- **Financial Analysis**
  - Income statement and balance sheet visualizations
  - Frontend powered by React + TypeScript
  - Financial charts and visual insights

- **User Interaction**
  - Commenting system for user-generated discussions on portfolios and stocks

---

## Tech Stack

- **Frontend**: React (TypeScript)
- **Backend**: ASP.NET Core, Entity Framework Core
- **Database**: SQL Server
- **Authentication**: JWT, ASP.NET Identity Core
- **Architecture**: RESTful APIs, DTOs, MVC Pattern
